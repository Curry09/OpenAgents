本项目的取证判断/纪律完全遵循 [`../SKILL.md`](../SKILL.md)，此处只做指针，不复制其内容：

- **判断三分类**：UI 可见 → 截图；UI 不可见但改产品行为 → 真实运行日志文本 + 触发上下文；纯内部实现 → 相称测试。见 SKILL.md「核心原则」。
